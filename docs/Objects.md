# Objects

Objects have some builtin variables that you can modify or read from. Here is a list of known builtin variables.

#### Object Variables

| Variables         | Is Used | Read-Only |
| ----------------- | ------- | --------- |
| `direction`       | true    | false     |
| `friction`        | true    | false     |
| `gravity`         | false   | false     |
| `gravity_direction` | false   | false     |
| `hspeed`          | true    | false     |
| `vspeed`          | true    | false     |
| `xstart`          | true    | true      |
| `ystart`          | true    | true      |
| `x`               | true    | false     |
| `y`               | true    | false     |
| `xprevious`       | true    | true      |
| `yprevious`       | true    | true      |
| `sprite_index`    | true    | false     |
| `sprite_width`    | true    | true      |
| `sprite_height`   | true    | true      |
| `sprite_xoffset`  | true    | true      |
| `sprite_yoffset`  | true    | true      |
| `image_alpha`     | true    | false     |
| `image_angle`     | true    | false     |
| `image_blend`     | true    | false     |
| `image_index`     | true    | false     |
| `image_number`    | true    | true      |
| `image_speed`     | true    | false     |
| `image_xscale`    | true    | false     |
| `image_yscale`    | true    | false     |
| `bbox_bottom`     | true    | false     |
| `bbox_left`       | true    | false     |
| `bbox_right`      | true    | false     |
| `bbox_top`        | true    | false     |
