# WeaponSetWeaponModData

### Syntax

`WeaponSetWeaponModData(item_id , mod_type, default_item_id, required=true, x=0, y=0, attachment_array=[]);`

**Returns** undefined.

| **Argument**     | **Type** | **Description**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| :--------------- | :------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| item_id          | String   | A name to use as a reference to the item.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| mod_type         | String   | Defines the type of weapon mod we're referring to. See [Weapon Mod Types](Weapon Mod Types) for a list of available mod types.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| default_item_id  | String   | The item id of the weapon mod that should be on this weapon by default.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| required         | Boolean  | Whether or not this weapon mod is required for the weapon to function.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| x                | Real     | The x position that weapon mods should connect to for this mod type.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| y                | Real     | The y position that weapon mods should connect to for this mod type.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| attachment_array | Array    | An array of attachment slots and positions. See the example provided down below.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |

Sets the weapon mod data for the specified weapon. This is useful for defining the default attachments for various mod types. See the [Weapon Mod Types](Weapon Mod Types) page for all available weapon mods.

An important note, foregrips can only be attached to "att_1" on weapons.

### Example:

```
WeaponModCreate("mod_test_magazine", "magazine", 0, 0, 0, 0, 0, false, ["test_weapon"])
WeaponModSetWeaponModData("test_weapon", "magazine", "mod_test_magazine", true, 0, 0)
WeaponModCreate("mod_test_handguard", "handguard", 0, 0, 0, 0, 0, false, ["test_weapon"])
WeaponModSetWeaponModData("test_weapon", "handguard", "mod_test_handguard", true, 0, 0, [["att_1",5,5]])
WeaponSetMagazineModCapacity("mod_test_magazine", 20)
```

The above code creates a weapon mod, assigns that weapon mod to be the default magazine mod for "test_weapon", and then sets the mod's magazine capacity to 20.
