Generates a money-goal survival objective to be used with a quest. This function should used to provide an objective to the function [QuestAddObjective](undefined).

### Example:

```
-- Create our quests
QuestCreate("approach_quest")
-- Set the quest name
QuestAddObjective("approach_quest", QuestObjectiveTypeApproach( obj_tree, 128, MAP_forest, 0, "" ) )
```

The above code creates a new quest and adds an objective to it. The objective is to approach the object, "obj_tree", on the forest map, and to get within a 128 pixel radius of it.
