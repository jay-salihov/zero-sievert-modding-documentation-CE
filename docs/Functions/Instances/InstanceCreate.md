# InstanceCreate

### Syntax

`InstanceCreate(x,y,object_index);`

**Returns** undefined.

| **Argument**   | **Type**       | **Description**                            |
| :------------- | :------------- | :----------------------------------------- |
| x              | Real           | The x position to spawn the object.        |
| y              | Real           | The y position to spawn the object.        |
| object_index   | Object Index   | The object index to create an instance of. |

Create a new instance of an object.

### Example:

```
InstanceCreate(30,30,obj_enemy_blink)
```

The above code creates an instance of a new object.
