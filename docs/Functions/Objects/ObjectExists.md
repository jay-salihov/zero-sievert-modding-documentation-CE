# ObjectExists

### Syntax

`ObjectExists(object_id);`

**Returns** *true* if the object exists and *false* if it does not.

| **Argument** | **Type** | **Description**                                  |
| :----------- | :------- | :----------------------------------------------- |
| object_id    | String   | The ID to use when referring to the object later. |

Checks if an object exists.

### Example:

```
ObjectExists("test_object")
```

The above code will check if an object exists.
