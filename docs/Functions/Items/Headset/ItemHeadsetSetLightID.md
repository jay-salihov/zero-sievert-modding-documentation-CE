# ItemHeadsetSetLightID

### Syntax

`ItemHeadsetSetLightID(item_id, torch_sprite);`

**Returns** “* **true** *“, if successful, otherwise it will crash.

| **Argument** | **Type**          | **Description**                                   |
| :----------- | :---------------- | :------------------------------------------------ |
| item_id      | String            | The name of the item to update.                   |
| torch_sprite | String (sprite) | What sprite should be displayed for the |

As long as **ItemHeadsetSetType()** has been set to "torch" this can be used to change the sprite used as the torch.
