# ItemInjectorSetMaxHp

### Syntax

`ItemInjectorSetMaxHp(item_id, max_hp);`

**Returns** “*__true__*“, if successful, otherwise it will crash.

| **Argument** | **Type** | **Description**                               |
| :----------- | :------- | :-------------------------------------------- |
| item_id      | String   | The name of the item to update.               |
| max_hp       | Real     | Amount to change the players HP.              |

While the Injector is active how much to change the players HP.

Note: *This could be a negative number to reduce the players HP.*
