# ItemInjectorSetBleedImmune

### Syntax

`ItemInjectorSetBleedImmune(item_id, bleed_immune);`

**Returns** “*__true__*“, if successful, otherwise it will crash.

| **Argument** | **Type** | **Description** |
|---|---|---|
| item_id | String | The name of the item to update. |
| bleed_immune | true/false | Does this give player bleed immunity. |

The can be used to set if the injector gives the player Bleed immunity for the duration of the injector.
