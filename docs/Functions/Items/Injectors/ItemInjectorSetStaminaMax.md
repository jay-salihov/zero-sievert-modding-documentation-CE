# ItemInjectorSetStaminaMax

### Syntax

`ItemInjectorSetStaminaMax(item_id, stamina_max);`

**Returns** “*true*“, if successful, otherwise it will crash.

| **Argument** | **Type** | **Description**                                  |
|--------------|----------|--------------------------------------------------|
| item_id      | String   | The name of the item to update.                  |
| stamina_max  | Real     | Amount to change the players Stamina.            |

While the Injector is active how much to change the players Stamina. 

Note: *This could be a negative number to reduce the players Stamina.*
