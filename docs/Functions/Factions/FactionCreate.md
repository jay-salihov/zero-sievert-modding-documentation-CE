# FactionCreate

### Syntax

`FactionCreate(faction_id);`

**Returns** undefined.

| **Argument** | **Type** | **Description**                         |
| :----------- | :------- | :-------------------------------------- |
| faction_id   | String   | A name to use as a reference to the faction. |

Create a new faction that can be affected and referred to by its * **faction_id** *.

### Example:

```
-- Create a faction
FactionCreate("new_faction")
```

The above code creates a new faction.
