# ChestCreate

### Syntax

`ChestCreate(chest_id);`

**Returns** undefined.

| **Argument** | **Type** | **Description**                       |
| :----------- | :------- | :------------------------------------ |
| chest_id     | String   | A name to use as a reference to the chest. |

Create a new chest that can be affected and referred to by its *__chest_id__*.

### Example:

```
-- Create a chest
ChestCreate("new_chest")
```

The above code creates a new chest.
