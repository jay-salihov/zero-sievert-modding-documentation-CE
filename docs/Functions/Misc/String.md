# String

### Syntax

`String(value);`

**Returns** the value as a string.

| **Argument** | **Type**      | **Description**                               |
| :----------- | :------------ | :-------------------------------------------- |
| value        | String/Real | The value you would like to return as a string. |

Returns the value provided as a string. For example, passing in a value like 10, it would return it as "10".

### Example:

```
ShowMessage("The number is " + String(10));
```

The above code will popup a message that says "The number is 10".
