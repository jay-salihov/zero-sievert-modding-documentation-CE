# ShowMessage

### Syntax

`ShowMessage(str);`

**Returns** undefined.

| **Argument** | **Type** | **Description**                                                                       |
| :----------- | :------- | :------------------------------------------------------------------------------------ |
| str          | String   | The string to show in the message. You can also enter a real or other data types such as arrays/structs. |

Pops up a message showing the argument that was given.

### Example:

```
let _value = "hello world!"; ShowMessage(_value);
```

The above code will popup a message that says "hello world!".
