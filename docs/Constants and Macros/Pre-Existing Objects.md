# Pre-Existing Objects

You can create pre-existing objects with `instance_create()` but you'll need to know what objects are available to you. Here is a comprehensive list of all the objects made available.

| Player     | Notes                   |
| :--------- | :---------------------- |
| obj_player | This is the player object. |

| Parent Objects         | Notes                                   |
| :--------------------- | :-------------------------------------- |
| obj_npc_parent         | Parent of all NPC objects               |
| obj_npc_human_parent   | Parent of all human NPC objects (child of `obj_npc_parent`)   |
| obj_enemy_mutant_parent| Parent of all mutant NPC objects (child of `obj_npc_parent`)   |
