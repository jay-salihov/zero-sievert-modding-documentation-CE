# Weapon Reload Types

When creating weapons you'll be able to give them a specific reload type, below is a list of available options.

| **Weapon Reload Types** | Descriptions                                                                                                                                                              |
| :---------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| "magazine"              | When reloading, the gun ejects the magazine and you'll get a full magazine worth of ammo.                                                                                  |
| "sniper_single"         | Reloading puts in a single bullet at a time and the reload can be interrupted.                                                                                             |
| “shotgun_single”        | Reloading puts in a single bullet at a time and the reload can be interrupted. Changes the sound that is used compared to "sniper_single". |
