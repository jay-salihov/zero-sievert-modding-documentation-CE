# Faction Reputation

When settings up faction reputations you can use these macros to quickly determine faction relations.

| **Faction Reputation Macros** | Value | Relationship Status |
|-------------------------------|-------|-----------------------|
| FACTION_REP_min               | 0     | Hostile               |
| FACTION_REP_max               | 1000  | Allies                |
| FACTION_REP_enemy               | 250   | Hostile               |
| FACTION_REP_ally                | 450   | Allies                |
| FACTION_REP_join                | 600   | Allies<br/>(Used for joining factions which is currently not supported) |
