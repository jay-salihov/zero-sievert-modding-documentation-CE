# Weapon Attachment Slots

Weapon attachment slots are used for the "foregrip", "laser", and "torch" mods. This is a list of the available attachment slots.

| Attachment Slots |
| ---------------- |
| "att_1"          |
| "att_2"          |
| “att_3”          |
| “att_4”          |

Attachment slot 4 ("att_4") is used primarily as the top-mount, and it will flip the sprites for attachments vertically. A laser attachment on the bottom would flip vertically if assigned to attachment slot 4.
