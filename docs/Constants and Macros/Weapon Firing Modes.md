# Weapon Firing Modes

When creating weapons you'll be able to give them a specific firing mode, below is a list of available options.

| **Weapon Firing Modes** | Descriptions                                                                  |
| :------------------------ | :---------------------------------------------------------------------------- |
| "automatic"               | The gun can be fired repeatedly by holding down the fire button.              |
| "semi_automatic"          | The gun can only be shot once per press of the fire button.                   |
| “bolt_action”           | Similar to the "semi_automatic" firing mode except a sound is played after each shot. |
