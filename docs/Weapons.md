# Weapons

Zero Sievert's gameplay is centered around weapons and using them to keep yourself alive. It won't be a surprise to you that the weapon system is fairly complicated and that modifying/creating weapons requires some basic understanding of the underlying systems.

## Weapon Components

See the [Weapon Mod Types](Weapon Mod Types) page for all available weapon mods.

Every weapon is made up of various parts. Here's a list of all available weapon parts.

*   Stock
*   Grip
*   Barrel
*   Handguard
*   Magazine
*   Brake (Muzzle)
*   Scope
*   Attachment 1
*   Attachment 2
*   Attachment 3
*   Attachment 4

The 4 attachment slots can be any of the following components.

*   Foregrip
*   Laser
*   Torch (flashlight)

## Required Components

Every weapon has a base component which is the part of the gun with the trigger and such, right in the middle of the gun. All other components connect to this part of the gun.

<span>![](image.png)</span>

Each component can be set as required or not, meaning you *could* have a gun that is functional even with just this center portion.

## Non-moddable Weapons

Weapons can be set to be non-moddable. This is useful for special weapons that you don't want to be modified. It's also much easier to make a gun when you don't have to build out each component.
