# Mod Upload Errors and Requirements

##### Pre Check Warnings: (done before starting an upload)

- No Internet
- Steam not active
- Steam not logged in
- Directory does not exist
- init.script is a mandatory file
- metadata.ini is a mandatory file
- Missing 'name' in metadata.ini
- Missing 'description' in metadata.ini
- Missing 'version' in metadata.ini
- Missing 'author' in metadata.ini
- icon.png is required in mod folder

##### During Upload:

- Error: Folder of mod not found or not readable.
- Notice: Steam stopped replying, unable to find status.
- Steam returned invalid during upload. Maybe Steam Cloud storage is full or mod/icon is too big?
- Warning: Problem getting progress from Steam. (may still have uploaded)

##### During Download:

- Empty mod
- Steam failed to download
- Important file missing from mod.
